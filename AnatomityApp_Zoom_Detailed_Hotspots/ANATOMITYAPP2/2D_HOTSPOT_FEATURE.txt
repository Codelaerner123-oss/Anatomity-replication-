What changed in this revision:
1. Pinch-to-zoom was added to every 2D anatomy image (100% to 500%).
2. When zoomed in, drag the image to pan around it.
3. - / RESET / + controls were added as an alternative to gestures.
4. Glowing marker visuals automatically become smaller as zoom increases, so dense structures do not cover each other.
5. Detailed markers are progressive: major structures appear at 100%, while smaller structures appear only at higher zoom levels.
6. The screen shows how many markers are currently visible and the next zoom level that reveals more detail.
7. Body-part information still stays hidden until a marker is tapped.
8. Switching organ systems resets the selected body part and the zoom state.

Implementation notes:
- Images are stored in app/src/main/res/drawable-nodpi/.
- Hotspot positions are normalized values from 0.0 to 1.0.
- Each AnatomyPart has a minZoom value that controls when a fine-detail marker appears.
- Hotspot definitions and the zoom/pan UI are in MainActivity.kt.
- The 3D page remains a placeholder because no 3D model asset has been supplied yet.

Build note:
